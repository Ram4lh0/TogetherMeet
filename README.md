# TogetherMeet

TogetherMeet é uma aplicação web para organizar eventos em grupo, escolher disponibilidades e encontrar o melhor horário comum entre os participantes.

A aplicação permite criar eventos com várias datas possíveis, recolher a disponibilidade de cada participante, visualizar os melhores horários através de uma grelha/heatmap e, no fim, confirmar um horário final. Depois de confirmado, o evento fica associado ao histórico dos utilizadores.

---

## Funcionalidades principais

- Criação de eventos com múltiplas datas possíveis
- Escolha de intervalos horários personalizados
- Grelha de disponibilidade por participante
- Heatmap com os horários mais compatíveis
- Lista automática dos melhores horários
- Sistema de autenticação com Supabase
- Histórico de eventos confirmados por utilizador
- Confirmação final do evento pelo organizador
- Interface responsiva, pensada para mobile
- Integração experimental com disponibilidade de campos via Playtomic
- Redirecionamento para reserva externa na Playtomic
